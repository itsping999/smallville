# Agent Cognitive Architecture

## Pipeline Overview

Each agent implements a cognitive pipeline per simulation tick:

```
Perceive -> Retrieve Memories -> [Reflect?] -> Assess Needs -> Plan -> Decide -> Execute -> Record
```

## 1. Perception [Paper]

Agents perceive their environment as natural language context:

```python
def build_perception(agent, world, sim_time):
    location = world.get_location(agent.location_id)
    others = world.get_agents_at(agent.location_id)
    objects = world.get_objects_at(agent.location_id)
    weather = world.get_weather()
    
    return {
        "location": f"You are at {location.name}. {location.description}",
        "people": [f"{a.name} ({a.current_activity})" for a in others if a.id != agent.id],
        "objects": [f"{o.name} ({', '.join(o.possible_actions)})" for o in objects],
        "time": sim_time.strftime("%A, %B %d, %I:%M %p"),
        "weather": weather.description,
        "needs": agent.needs.summary(),  # "Energy: 45/100, Hunger: 30/100..."
        "emotion": agent.emotion.dominant,
        "current_activity": agent.current_activity,
    }
```

## 2. Memory Retrieval [Paper]

Given perception context, retrieve top-K memories:

```python
score = alpha * recency + beta * importance + gamma * relevance

# recency = 0.99^(hours_since_last_access)
# importance = LLM-scored 1-10 (or heuristic for observations)
# relevance = cosine_similarity(query_embedding, memory_embedding)
```

Parameters:
- alpha = 1.0, beta = 1.0, gamma = 1.0 (default)
- K = 15 memories per retrieval
- Embeddings: hash-based 128-dim fallback (no external embedding API required)

## 3. Reflection [Paper]

When cumulative importance of recent memories exceeds threshold (150):
1. Select top-5 most important recent memories
2. Ask LLM: "Given these observations, what high-level insights can you generate?"
3. Store reflections as new memories with type "reflection"
4. Reflections have high importance (typically 7-9)

Reflection examples:
- "I've been feeling lonely lately because I haven't seen friends in a week"
- "My finances are tighter than usual; I should cut back on dining out"
- "The neighborhood seems quieter since the Johnsons moved away"

## 4. Needs Assessment [Extended]

Before planning, assess current needs:

```python
needs_priority = sorted(
    agent.needs.all_needs(),
    key=lambda n: compute_priority(n, agent, context),
    reverse=True
)
```

Priority computation considers:
- **Urgency**: How far below comfortable threshold (50) the need is
- **Personality weight**: Conscientiousness boosts work priority, extraversion boosts social
- **Emotional modifier**: Anxiety amplifies safety/comfort needs
- **Time appropriateness**: Eating at mealtimes gets bonus
- **Situational**: At work -> can't immediately address personal needs

## 5. Planning [Paper + Extended]

### Daily Plan (generated each morning at wake)
```yaml
wake_up: "6:30 AM"
morning_routine: "6:30-7:15 bathroom + breakfast"
commute_to_work: "7:15-7:45 drive to Riverside Tech"
work_morning: "8:00-12:00 work tasks"
lunch: "12:00-12:45 eat at Sunrise Cafe"
work_afternoon: "1:00-5:00 work tasks"
commute_home: "5:00-5:30 drive home"
evening: "5:30-9:00 cook dinner, relax, read"
bedtime: "10:00 PM"
```

### Action Plan (reactive, 5-15 min granularity)
Generated by LLM based on current context. Includes:
- What to do right now
- Expected duration
- Target location/object/person
- Emotional motivation

### Plan Modification Triggers
- Encountered another agent -> consider conversation
- Need threshold crossed -> reprioritize
- Environment event (rain, store closed) -> adapt
- Completed current action -> decide next
- Memory-driven insight (forgot something) -> backtrack

## 6. Decision Making [Extended]

### Action Selection

The LLM receives full context and selects from available actions:

```python
prompt = f"""
You are {agent.identity.name}. {agent.identity.personality_description}

Current state:
- Location: {perception.location}
- Time: {perception.time}
- Needs: {perception.needs}
- Emotion: {perception.emotion}
- Current activity: {perception.current_activity}

People nearby: {perception.people}
Objects you can use: {perception.objects}

Recent memories:
{format_memories(retrieved_memories)}

Your daily plan says: {agent.daily_plan}

What do you do next? Choose ONE action:
- move: go to a specific location
- interact_object: use an object at current location
- converse: talk to someone nearby
- rest: take a break
- [activity-specific actions]

Consider your personality, needs, and current situation.
"""
```

### Event Chains

When a complex action is chosen (e.g., "go to sleep"), the runtime decomposes it:

```python
EVENT_CHAINS = {
    "go_to_sleep": [
        Action("commute_home", condition=lambda a: a.location != "home"),
        Action("enter_house"),
        Action("use_bathroom", duration=15),
        Action("go_to_bedroom"),
        Action("get_in_bed"),
        Action("sleep", duration=480),  # 8 hours
    ],
    "prepare_meal": [
        Action("go_to_kitchen"),
        Action("get_ingredients", condition=lambda a: a.has_food),
        Action("cook", duration=30),
        Action("eat", duration=20),
        Action("clean_up", duration=10),
    ],
    "go_to_work": [
        Action("morning_routine", duration=30, condition=lambda a: a.location == "home"),
        Action("commute_to_work"),
        Action("arrive_at_workplace"),
        Action("start_work"),
    ],
    "exercise_routine": [
        Action("go_to_gym_or_park"),
        Action("change_clothes", condition=lambda a: a.at_gym),
        Action("exercise", duration=45),
        Action("shower", duration=15),
        Action("change_back"),
    ],
    "social_visit": [
        Action("decide_destination"),  # LLM picks where
        Action("commute_to_location"),
        Action("arrive_and_greet"),
        Action("socialize", duration=60),
        Action("say_goodbye"),
        Action("commute_home"),
    ],
    "go_shopping": [
        Action("make_shopping_list"),
        Action("commute_to_store"),
        Action("browse_aisles", duration=15),
        Action("purchase_items"),
        Action("commute_home"),
        Action("put_away_items"),
    ],
    "medical_visit": [
        Action("commute_to_clinic"),
        Action("check_in"),
        Action("wait", duration=15),
        Action("see_doctor", duration=30),
        Action("fill_prescription", condition=lambda a: a.needs_medication),
        Action("commute_home"),
    ],
}
```

Chain interruption: If during execution a higher-priority need arises, the LLM is consulted:
```
"You are currently [driving home] but you suddenly feel [very unwell]. 
Your health is at 25/100. Do you continue home or change plans?"
```

## 7. Conversation System [Paper + Extended]

### Trigger
When two agents share a location, there's a base probability of conversation (30-60%, modified by personality and relationship).

### Dialogue Generation
```python
prompt = f"""
You are {agent_a.name}, talking to {agent_b.name} at {location}.
Your relationship: {relationship.type} (closeness: {relationship.closeness})
Your personality: {agent_a.personality}
Your current mood: {agent_a.emotion.dominant}
Recent relevant memories: {top_3_memories}

Generate a natural 2-4 turn conversation. Topics should be:
- Related to shared experiences or current context
- Influenced by your mood and relationship
- Potentially including gossip or information sharing
"""
```

### Information Propagation [Paper]
- During conversations, agents may share memories
- Shared memories become new memories for the listener
- Information can spread through 3+ hops (gossip chains)
- Importance of shared information affects propagation likelihood
